## 🚀 Cara Pemasangan (Pilih Salah Satu)

### 1. Bantuan AI Automatik (Paling Mudah)
Hanya tampal prompt ini pada AI anda (Google Antigravity / Claude Code / Cursor):
```text
install ni dekat tv rumah saya: https://github.com/chickencrispy/glasstv-home
```

### 2. Guna Telefon Pintar (Tanpa PC)
* **Android**: Guna aplikasi percuma **Bugjaeger Mobile ADB** di telefon untuk pasang APK dan buang iklan.
* **iPhone (iOS)**: Hantar APK ke TV guna aplikasi percuma **LocalSend** atau **Send Files to TV**.

### 3. Pasang Manual Guna Pendrive (USB)
1. Salin `glass-tv-home.apk` ke dalam pendrive USB.
2. Cucuk ke Android TV anda.
3. Buka pengurus fail di TV (cth: *File Commander* atau *FX File Explorer*), klik fail APK dan tekan **Install**.
4. Tekan butang **Home** pada remote TV dan pilih **Glass TV Home** sebagai *Always / Sentiasa*.

AI akan menyambung ke TV, memasang APK terkini (`adb install -r`), dan melancarkan semula skrin utama dalam masa 5 saat secara senyap tanpa mengganggu sebarang tetapan anda.

### Kaedah B: Auto-Update Terus Dari TV (In-App OTA Updater)
Tanpa komputer dan tanpa bantuan AI:
1. Pada skrin utama TV, halakan remote ke butang **Settings (ikon gear ⚙️)**.
2. Pilih **`🔄 Check for Updates`**.
3. Sistem akan menyemak versi terkini dari GitHub secara automatik. Jika terdapat patch baharu, tekan **Muat Turun & Pasang** untuk mengemas kini serta-merta!
*(Selain itu, TV juga akan menyemak kemas kini di latar belakang setiap kali aplikasi dibuka).*
